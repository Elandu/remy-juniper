# JUNIPER — Branding

Public name: **Juniper**
Engine: Nadeko (internal only — never surfaced to members)

## Palette

| Role | Name | Hex |
|------|------|-----|
| Base | Charcoal | `#1B1A1D` |
| Light text/details | Warm cream | `#E8E1D8` |
| Primary accent | Muted sage | `#89917A` |
| Secondary accent | Dusty mauve | `#8C6F7D` |

Rules:

- Charcoal is the visual base.
- Cream for light text/details.
- Sage and mauve used sparingly as accents.
- Default embed colour: **#89917A** (sage).
- Secondary/accent colour where multiple are supported: **#8C6F7D** (mauve).

## Prohibited

- neon purple gradients
- bright pink
- anime artwork
- hearts everywhere
- flower branding
- excessive emoji
- generic gamer RGB aesthetics

## Feel

"a cosy, slightly alternative internet clubhouse" — mature, cosy, alternative,
understated, slightly weird, internet-native, playful without being childish,
occasional dry humour.

Must NOT feel like: anime, waifu/gacha, RPG, casino, generic gaming Discord,
corporate Patreon bot, hyperactive "cute" bot, dedicated music bot.

Reference only (never themed directly): cosy games (Animal Crossing / Pokopia),
alternative artists (Nirvana, Foo Fighters, Hayley Williams).

## Visual mark (avatar)

- charcoal background
- simple cream botanical/geometric mark
- subtle juniper-leaf or four-point-star influence
- extremely simple, flat design
- no character/mascot face, no anime, no text inside
- readable as a tiny Discord avatar

Asset home: `data/juniper/assets/` (see `COMMUNITY_SETUP.md` for exact
filenames/sizes). Do not use Nadeko artwork.

## Tone

Short, clear, understated, friendly, occasionally dry. Australian/British
spelling. Default ZERO emoji; one only where it carries meaning. Never:
✨ 🌸 💖 uwu senpai -sama bestie!!! OMG!!! LET'S GOOO!!!
